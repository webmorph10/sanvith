# Sanvith B — Portfolio

React + Vite + Tailwind CSS glassmorphism portfolio.

## Getting started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build -> dist/
```

Edit `src/data.ts` to update all content (name, education, skills, projects, experience, certifications).
Replace `public/sanvith-portrait.jpg` to change the portrait photo.
